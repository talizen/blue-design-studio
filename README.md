# blue. — Design Studio

A dark, cinematic one-page site for design studios and creative agencies. A moonlit hero with a live local clock, a journey section where one photo splits into three cards, an expanding services list, a featured-work carousel driven by CMS, testimonials, stats, team contact and a photo footer — all with smooth scroll and scroll-linked motion.

## Quick start

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

## Build & deploy

```bash
npm run build
```

The static site is written to `dist/`. Upload it to any static host — Vercel, Netlify, Cloudflare Pages, GitHub Pages, S3 or your own server.
